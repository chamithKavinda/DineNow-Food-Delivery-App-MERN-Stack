# Dine Now - Food Delivery Website 🍽️

**Dine Now** is a full-stack Food Delivery Web Application where users can browse a menu, place orders, and pay online securely via Stripe. Admins can manage food items, monitor orders, and update the menu through a dedicated admin panel.

This project is built using the **MERN stack** (MongoDB, Express.js, React.js, Node.js).

## Features ✨

### User Side
- Browse and select food items from the menu.
- Add user authentication (Sign In/Sign Up).
- Add selected items to the cart.
- Place orders and pay securely using Stripe payment gateway.
- Receive real-time feedback with toast notifications.
- Order tracking for users.

### Admin Side
- Secure Admin Panel to manage the system.
- Add, edit, and delete food menu items.
- View and handle all customer orders.
- Update order status (e.g., Pending, Preparing, Delivered).
- Admin dashboard with analytics.

---

## Tech Stack 🛠️

- **Frontend**: React.js, React Router, Axios, React Toastify
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose ODM)
- **Authentication & Payment**: Stripe Payment Gateway

## Installation & Setup Guide 🚀

### Prerequisites
- Node.js and npm installed
- MongoDB installed and running (or use MongoDB Atlas)
- Stripe account for API keys

### 1. Clone the Repository
```bash
git clone https://github.com/chamithKavinda/DineNow-Food-Delivery-App.git
cd dine-now
```

### 2. Backend Setup
```bash
cd backend
npm install
```

### 3. Create .env file
```bash
PORT=5000
MONGO_URI=your_mongo_db_connection_string
STRIPE_SECRET_KEY=your_stripe_secret_key
STRIPE_PUBLIC_KEY=your_stripe_public_key
```

### 4. Start Backend Server
```bash
npm run server
```

### 5. Frontend Setup
```bash
cd frontend
npm install
```

### 6. Start Frontend Server
```bash
npm run dev
```
